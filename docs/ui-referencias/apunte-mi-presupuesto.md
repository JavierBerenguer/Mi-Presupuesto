# Referencia: formulario «Nuevo apunte» de Mi Presupuesto (observado en el emulador, sin datos personales)

Estructura (de arriba abajo):
- Barra superior: flecha atrás, título que cambia con el tipo («Añadir gasto» / «Añadir ingreso» / «Añadir transferencia»), acción «Guardar y añadir otro» (check con +) y «Guardar» (check).
- Selector de tipo con tres opciones en fila: Gasto / Ingreso / Transferencia (el gasto se colorea en rojo cuando está activo).
- Tarjeta «Usar plantilla» (rellena el formulario desde una plantilla guardada).
- Tarjeta de campos, etiqueta a la izquierda y campo a la derecha con línea inferior: Título, Comentario, Fecha, Importe, Categoría (con botón para limpiar; «Sin asignar» por defecto), Cuenta. En Transferencia: Cuenta origen y Cuenta destino, con botón para intercambiarlas; la categoría sigue disponible.
- Casilla «Movimiento recurrente» (despliega periodicidad).
- «Recordatorio» (No por defecto).
- «Añadir foto».
- Botón «Vaciar campos».
- Selector de categoría a pantalla completa: pestañas Favoritas / Categorías / A-Z, buscador, lista y botón «+» para crear categoría; las subcategorías se muestran en el propio selector.
- La cuenta por defecto es la última usada.
