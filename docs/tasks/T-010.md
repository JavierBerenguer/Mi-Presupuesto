# T-010 — Gráficos Canvas interactivos

- **Estado:** pendiente
- **Rama:** `codex/t-010-graficos`
- **Depende de:** nada (base: `claude/fase-3-mvp`)

## Objetivo
Tres componentes de gráfico en Compose Canvas, sin dependencias nuevas, legibles en oscuro y claro, con selección táctil. Los usarán Inicio y Patrimonio. Lee antes `docs/tasks/COMMON.md`.

## Contrato (firmas exactas)
Paquete `com.mipatrimonio.app.ui.common.charts`:
```kotlin
data class ChartPoint(val label: String, val value: Long)                          // value en unidades menores
data class BarGroup(val label: String, val incomeMinor: Long, val expenseMinor: Long)
data class DonutSlice(val label: String, val valueMinor: Long, val color: Color)

@Composable fun LineChart(points: List<ChartPoint>, formatValue: (Long) -> String, description: String, emptyText: String, modifier: Modifier = Modifier)
@Composable fun GroupedBarChart(groups: List<BarGroup>, incomeLabel: String, expenseLabel: String, formatValue: (Long) -> String, description: String, emptyText: String, modifier: Modifier = Modifier)
@Composable fun DonutChart(slices: List<DonutSlice>, centerLabel: String, formatValue: (Long) -> String, description: String, emptyText: String, modifier: Modifier = Modifier)
```
`description` es el `contentDescription` semántico del gráfico (lo pasa quien lo usa, ya en español). `emptyText` se muestra cuando no hay datos. Los importes son `Long` (nunca `Double` para dinero; `Float` solo para coordenadas de dibujo).

## Requisitos
1. **LineChart**: línea con área suave translúcida bajo ella, eje base en 0 cuando hay negativos (línea de cero visible), 3 líneas guía horizontales tenues, etiquetas (primera, central y última) bajo el eje, altura ~200 dp. Interacción: tocar o arrastrar selecciona el punto más cercano (`detectTapGestures` + `detectHorizontalDragGestures`), dibuja marcador y muestra encima `label` y `formatValue(value)`. Sin selección muestra el último punto por defecto.
2. **GroupedBarChart**: barras de ingresos (`MoneyColors.positive`) y gastos (`MoneyColors.negative`) por grupo, leyenda con `incomeLabel`/`expenseLabel`, etiquetas de grupo bajo las barras (si hay muchos grupos, muestra solo algunas para que no se solapen), selección táctil que muestra ambos importes del grupo.
3. **DonutChart**: anillo con `sweep` proporcional a `valueMinor`, `centerLabel` en el centro, leyenda debajo (color + etiqueta + importe + porcentaje entero), selección táctil de un sector (resaltarlo y mostrar su detalle). Agrupa en «otros» NO: recibe ya las porciones.
4. Colores del tema (`MaterialTheme.colorScheme`) para ejes/etiquetas/guías; nada en blanco/negro fijo. Deben verse bien en oscuro y claro.
5. **Casos degenerados sin crashear ni dividir por cero**: lista vacía (muestra `emptyText`), un solo punto, todos los valores iguales, todos ceros, valores negativos, `valueMinor` ≤ 0 en donut (se ignoran las porciones no positivas; si no queda ninguna → `emptyText`), un único sector del 100 %.
6. **Matemática pura en `ChartMath.kt`** (testeable, sin Compose): p. ej. `linePoints(values: List<Long>, width: Float, height: Float): List<Offset>` (mapeo con eje base correcto), `nearestIndex(x: Float, count: Int, width: Float): Int`, `donutSweeps(values: List<Long>): List<Float>` (grados; suman 360 salvo lista vacía), `percentages(values: List<Long>): List<Int>`. Puedes elegir firmas parecidas si lo justificas en el informe.

## Tests obligatorios
`ChartMathTest`: mapeo con positivos, con negativos y con todos iguales; un solo punto; `nearestIndex` en extremos y con `count=1`; `donutSweeps` suma 360, ignora no positivos, lista vacía; `percentages` con redondeo razonable y sin división por cero.
