# T-041 — Cotizaciones automáticas (Twelve Data + CoinGecko), claves seguras y actualización periódica

- **Estado:** pendiente

## Objetivo
`datos-privados/inversiones-requisitos.md`, secciones 2 y 7:
- La app actualiza periódicamente el precio de cada activo en cartera.
- Sin conexión o sin proveedor se usa el último precio conocido y se indica su antigüedad.
- Si no hay cotización, se sigue pudiendo introducir el precio a mano (ya existe; no lo rompas).
- Se distingue si un precio es retrasado o de cierre cuando esa información exista. **Nunca** se etiqueta nada como «tiempo real»: los planes gratuitos no lo garantizan.
- Sin conexión todo lo demás de Inversiones sigue funcionando igual.

El alta de activos a partir del ISIN (OpenFIGI) NO es de esta ficha: será T-042. Aquí el identificador de cotización de cada activo se configura a mano en el formulario del activo.

## Decisiones ya cerradas (Claude, con autorización previa del usuario)
- Proveedores: **Twelve Data** para acciones y ETF, **CoinGecko** (plan Demo) para criptomonedas. Fondos de inversión, fondos indexados y préstamos P2P quedan sin proveedor (precio manual). Permiso `android.permission.INTERNET` autorizado por el usuario.
- **Cero dependencias nuevas, no se toca Gradle:** HTTP con `java.net.HttpURLConnection` (solo `https://`), JSON con `org.json` (incluido en Android), cifrado con Android Keystore (`javax.crypto`, AES/GCM, clave no exportable en `AndroidKeyStore`). No uses `androidx.security:security-crypto` (obsoleta).
- Datos verificados por Claude en la documentación oficial el 2026-09-28:
  - Twelve Data: base `https://api.twelvedata.com`, endpoint `GET /quote?symbol=<SYM>&mic_code=<MIC>`. La clave va **en la cabecera** `Authorization: apikey <KEY>` (nunca en la URL, para que no aparezca en logs ni mensajes de error). Campos usados de la respuesta: `symbol`, `currency`, `close` (string decimal), `timestamp` (epoch s), `is_market_open` (bool). Error: `{"code": <int>, "message": "...", "status": "error"}` (p. ej. 401 clave inválida, 429 límite). Filtrar por `isin` es un complemento de pago: no lo uses. Plan gratuito: 8 créditos/minuto, 800/día; 1 crédito por símbolo en `/quote`.
  - CoinGecko Demo: base `https://api.coingecko.com/api/v3`, `GET /simple/price?ids=<id1,id2>&vs_currencies=<eur>&include_last_updated_at=true&precision=full`. Clave Demo en cabecera `x-cg-demo-api-key` (opcional: si no hay clave, llama igual sin cabecera). Respuesta: `{"bitcoin": {"eur": 76975.12, "last_updated_at": 1779092258}}`. `ids` es el id de CoinGecko (p. ej. `bitcoin`), no el ticker.

### Modelo (Room v8 → v9, migración aditiva)
1. `asset` gana `quoteProvider TEXT NULL` (`TWELVE_DATA` | `COINGECKO` | NULL = sin proveedor) y `quoteSymbol TEXT NULL` (Twelve Data: `SYMBOL` + `quoteMic`; CoinGecko: id de la moneda) y `quoteMic TEXT NULL` (MIC ISO 10383 para Twelve Data, p. ej. `XNAS`, `XETR`, `XMAD`; puede ser NULL para dejar que Twelve Data elija el mercado principal).
2. `asset_price` gana `quality TEXT NULL` (`RETRASADO` | `CIERRE` | NULL para precios manuales antiguos) y conserva `source` (`MANUAL`/`PROVEEDOR`) y `asOfEpochMillis`.
3. Dominio: `Asset` gana `quoteProvider: QuoteProvider? = null`, `quoteSymbol: String? = null`, `quoteMic: String? = null` (al final, con valor por defecto). `AssetPrice` gana `quality: PriceQuality? = null`. Mappers actualizados.
4. Test de migración 8→9 con datos previos, `9.json` generado por el build (no lo escribas a mano), sin `fallbackToDestructiveMigration`.

### Arquitectura
5. Interfaz de dominio `QuoteProvider` (o nombre equivalente) desacoplada: `suspend fun fetch(requests: List<QuoteRequest>): List<QuoteResult>`; cada resultado es éxito (`price: BigDecimal`, `currency`, `asOf`, `quality`) o error tipado (`SinClave`, `ClaveInvalida`, `LimiteAlcanzado`, `NoEncontrado`, `SinConexion`, `RespuestaInvalida`). Implementaciones `TwelveDataQuoteProvider` y `CoinGeckoQuoteProvider` en `data/quotes/`. El transporte HTTP detrás de una interfaz (`HttpClient` mínima) para poder testear con respuestas grabadas sin red.
6. Importes: parsea precios como `BigDecimal` desde el texto; nunca `Double`. Para CoinGecko usa `JSONObject.getString(...)`/`optString` sobre el valor numérico o `BigDecimal(obj.get(...).toString())`, nunca `getDouble`. Valida precio > 0.
7. **Divisa:** el precio se guarda solo si la divisa devuelta coincide con la divisa del activo (`Asset.currency`). Si no coincide, resultado `DivisaDistinta` y NO se guarda (la conversión multidivisa no es de esta ficha). CoinGecko se consulta con `vs_currencies` = divisa del activo en minúsculas.
8. **Calidad:** Twelve Data → `CIERRE` si `is_market_open == false`, si no `RETRASADO`. CoinGecko → `RETRASADO`. `asOf` = marca temporal del proveedor (`timestamp`/`last_updated_at` × 1000), no la hora de la consulta.
9. **Repositorio `QuoteRepository`:** `refreshAll()` actualiza los activos no archivados con posición abierta (cantidad > 0) y `quoteProvider != null`. Agrupa CoinGecko en una sola llamada (`ids` separados por comas). Twelve Data: una llamada por activo, respetando **8 llamadas por minuto** con un limitador con reloj inyectable (testeable sin esperar). Guarda cada precio con `source = PROVEEDOR` y su `quality` usando el historial de precios existente (no sobrescribas el historial). Nunca borra ni modifica precios manuales. Devuelve un resumen (actualizados, fallidos por motivo, omitidos sin proveedor).
10. **Claves:** `SecretStore` (interfaz) con implementación `KeystoreSecretStore` (AES/GCM en `AndroidKeyStore`, texto cifrado + IV en un `SharedPreferences` propio, p. ej. `quote_secrets`). En tests usa una implementación en memoria (Robolectric no soporta `AndroidKeyStore`). Las claves: nunca en logs, excepciones, `toString`, estado de UI salvo como «configurada/no configurada», ni en exportaciones/copias de seguridad. `android:allowBackup` ya es `false`: no lo cambies.
11. **Actualización periódica:** `PeriodicWorkRequest` diario (`QuoteRefreshWorker`, nombre único, `ExistingPeriodicWorkPolicy.KEEP`) con restricción `NetworkType.CONNECTED`, encolado desde `AppContainer` junto al de T-038. Además, botón «Actualizar precios» en Inversiones que lanza `refreshAll()` y muestra el resultado. Sin proveedores configurados, el botón explica qué falta y no hace llamadas.
12. **UI:**
    - Ajustes → nueva sección «Cotizaciones»: campo para la clave de Twelve Data y para la clave Demo de CoinGecko (opcional), mostrados como «Configurada» con opción de cambiar/borrar; nunca se muestra la clave guardada. Texto breve: los datos gratuitos pueden ir retrasados o ser de cierre, y dónde obtener cada clave (sin enlaces inventados: solo los dominios `twelvedata.com` y `coingecko.com`).
    - Formulario de activo: campos «Proveedor de cotización» (Ninguno / Twelve Data / CoinGecko, según el tipo de activo), «Símbolo» y, para Twelve Data, «Mercado (MIC)» opcional.
    - Allí donde hoy se muestra el precio de un activo (detalle de activo, posiciones): origen (Manual / Twelve Data / CoinGecko), calidad («Retrasado» / «Cierre»), fecha y hora de la cotización y antigüedad legible («hace 3 h», «hace 2 días»). Si el último precio tiene más de 3 días, indicador de precio antiguo.
13. Textos en español; `docs/tasks/COMMON.md` obligatorio (incluida la regla de `SettingsStoreRule` en tests).

## Casos límite a cubrir
Sin clave de Twelve Data (no llama, error `SinClave`); clave inválida (401); límite alcanzado (429 o `code` 429 en el JSON) — el resto de activos se reintenta en la siguiente ejecución, sin bucles; sin conexión (`IOException`) — conserva el último precio; símbolo inexistente; divisa distinta; precio 0, negativo o no numérico; respuesta JSON corrupta; activo archivado o sin posición abierta (no se consulta); activo sin proveedor (se omite); CoinGecko con varios ids y uno ausente en la respuesta; precio manual posterior a uno de proveedor (sigue mandando el más reciente por `asOf`, como hoy); worker sin red (lo reprograma WorkManager).

## Tests obligatorios
