- **Estado:** pendiente

- **Rama base:** `claude/fase-3-mvp` (tras integrar T-058)
- **Depende de:** T-058 (modelo, motor de plantillas y API del repositorio; lee su informe `docs/tasks/T-058.report.md` para los nombres exactos)

- **Tipo:** implementación

## Objetivo
Requisitos del usuario (`datos-privados/Documento de cambios/Documento.md`): cuando llega una notificación cuyo formato no se reconoce, se muestra en **Ajustes → Automatización de notificaciones**, donde el usuario selecciona **directamente sobre el texto** el texto clave y el texto variable, elige el tipo de operación y, opcionalmente, título, detalle y categoría; ve una **vista previa** del apunte antes de guardar; y puede **editar, desactivar o eliminar** estructuras y reglas.

## Decisiones ya cerradas
1. **Ubicación:** nueva entrada «Automatización de notificaciones» en la sección de automatización bancaria de «Ajustes» (junto a «Notificaciones bancarias», que sigue gestionando qué apps están autorizadas y su cuenta). La entrada antigua «Propuestas pendientes» solo se muestra mientras queden propuestas antiguas sin resolver; con cero, desaparece. Respeta la regla de T-053: cada destino en un solo sitio (`SecondaryMenuDestination`).
2. **Pestañas:** «Pendientes» (con contador) y «Estructuras».
3. **Pendientes:** lista de registros `PENDIENTE_ESTRUCTURA`, `PENDIENTE_REGLA` y `PENDIENTE_CUENTA`, del más reciente al más antiguo, con app, fecha, texto saneado e importe detectado resaltado. Acciones: «Enseñar» (o «Configurar comercio» si ya hay estructura), «Descartar». Para `PENDIENTE_CUENTA`: explicación y acceso a «Notificaciones bancarias» para asociar la cuenta.
4. **Enseñar una estructura (desde `PENDIENTE_ESTRUCTURA`):**
   - El texto se muestra como **palabras pulsables** (fichas). El importe detectado aparece ya marcado y no se selecciona.
   - Dos modos, «Marcar texto clave» y «Marcar texto variable»: el usuario pulsa la primera y la última palabra del fragmento (o una sola). Cada fragmento con su color y leyenda; se puede rehacer.
   - Campos: tipo de operación (nombre de la estructura, p. ej. «Pago con tarjeta»; se sugieren los ya usados), sentido («Según el signo: con + ingreso, sin signo gasto» por defecto / «Siempre ingreso» / «Siempre gasto»), y, como valores **de la estructura**, título, detalle y categoría opcionales; y como valores **de este comercio/persona/activo** (la regla específica), título, detalle y categoría opcionales. Explica en una línea la diferencia («para todos los pagos con tarjeta» / «solo para LOOMISP*CAFETERIA PARA»).
   - **Vista previa** siempre visible del apunte resultante (tipo, importe, cuenta, fecha, título, detalle, categoría) usando `previewFromRecord`. Si la plantilla no es válida (sin texto clave, o el texto clave y el variable se solapan), el botón Guardar se desactiva con el motivo.
   - Guardar crea estructura + regla, crea el apunte de ese registro y llama a `reprocessPending()`; muestra cuántos pendientes más se han automatizado con ella.
5. **Configurar comercio (desde `PENDIENTE_REGLA`):** muestra la estructura ya reconocida y el texto variable capturado; solo pide título, detalle y categoría de la regla, con vista previa. Guardar crea la regla, el apunte y reprocesa.
6. **Estructuras:** lista agrupada por app con nombre, sentido, nº de reglas, habilitada/deshabilitada. En el detalle: editar nombre, sentido y valores predeterminados; habilitar/deshabilitar; eliminar (confirmación: los apuntes ya creados se conservan). Lista de reglas específicas con su texto variable, título, detalle y categoría: editar, habilitar/deshabilitar, eliminar. Tras cualquier cambio, `reprocessPending()`.
7. **Ver la notificación original:** en la pantalla de edición de un movimiento creado desde una notificación (`recordForTransaction`), una fila «Notificación original» que muestra el texto saneado, la estructura y la regla aplicadas.
8. Accesibilidad: las fichas de palabras tienen tamaño táctil ≥ 40 dp y descripción para lectores de pantalla («palabra X, marcada como texto clave»). Textos en español; `docs/tasks/COMMON.md` obligatorio (incluida la regla de esperas de T-057).
